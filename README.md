# Python-Libraries-Implemented-in-C-Exploration
Exploring how to achieve high performance in Python by writing intensive programs in C.

https://canva.link/yk48o5pz9m4rdqx

I used AI as a learning tool to explore how C programs can be imported into Python programs to improve efficiency of computationally intensive operations. I wanted to explore how programs can integrate multiple languages to combine their best parts.

What I explored:

1. I learned about what cytypes is and used for, and how it handles conversions between integers represented in Python and C, etc. To explore this, I wrote a simple function in C that takes two integers, adds them, and returns the result. I imported it into a main Python program. As part of this, I learned about the differences between how C and Python store integers, and how Python has to store more information about variable type and reference data.

2. I learned what Numpy is and how it supports mathematical operations on entire arrays.
